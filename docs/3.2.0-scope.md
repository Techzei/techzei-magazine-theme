# Techzei Magazine Theme 3.2.0 scope

Status: implementation scope.

## Objective

Improve the v3.1.1 theme's mobile reading flow, editor/frontend consistency, article discovery, editorial reuse, settings visibility, and release validation while preserving the Twenty Twenty-Five block-theme architecture.

## Boundaries

- WordPress 6.7+ and PHP 7.4 compatibility.
- No page builder, frontend framework, external font, analytics, or production deployment.
- Preserve posts, media, menus, saved Site Editor customisations, public `techzei_tt5_*` hooks, and legacy shortcode names.
- Site Editor remains the owner of colours, fonts, branding, navigation, composition, and per-post content.
- Techzei Settings owns behaviour defaults only.

## Workstreams

1. Settings: add mobile sidebar, related-story mode, request-local resolver caching, and read-only theme/customisation diagnostics.
2. Templates and styles: put article actions immediately after content, improve mobile flow and card hierarchy, align archive/search treatments, and consolidate design tokens.
3. Editorial: make related stories more relevant and add native Review Verdict, Product Specifications, and Related Reading patterns without changing existing posts.
4. Interaction and assets: preserve accessible core navigation/search/ticker behaviour, translate labels, and verify editor/frontend asset parity.
5. Quality: validate PHP, JavaScript, JSON, blocks, packaging, upgrade safety, and the release workflow on pull requests and pushes.

## Acceptance

- Mobile article content reaches share, author, related, and comments before optional discovery modules.
- Explicit article templates continue to take precedence over the site default.
- Cards have consistent image sizing, metadata, long-title wrapping, and no-thumbnail states.
- Related results exclude the current post and prefer shared tags/categories with deterministic fallback.
- Settings diagnostics never overwrite or mislabel saved Site Editor templates.
- No image has both lazy loading and high fetch priority.
- Menu, search, ticker, reduced motion, keyboard focus, and no-JavaScript search remain usable.
- Existing shortcodes render safely, including uneven and malformed column content.
- CI validates pull requests and pushes; release packaging remains attached only to published releases.
- A validated ZIP has exactly one top-level `techzei-magazine-theme` folder containing `style.css`.

## Validation matrix

Test homepage, category/author/date archives, search results and empty search, page, 404, current and legacy articles, sidebar/no-sidebar templates, missing images, long titles, comments, tables, embeds, code, and legacy columns at 320, 375, 768, 1024, and 1440px. Include logged-out interactions, keyboard and Escape handling, sticky header/admin bar offsets, reduced motion, editor preview parity, PHP 7.4 syntax, WP_DEBUG notices where available, fresh install, 3.0.0 upgrade safety, and ZIP integrity.
