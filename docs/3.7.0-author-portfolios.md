# 3.7.0 author portfolios — local candidate

This is unreleased development work. No production profile, post, saved template,
navigation or Global Styles data is migrated or overwritten.

## Editorial ownership

- Existing profile: display name, biography, avatar, website, and the `twitter`
  social field. The theme adds no external avatar provider or frontend service.
- Users → Profile → Techzei author portfolio: optional editorial role (120
  characters), up to five favourite categories, up to three own published article
  links in display order. These are one versioned user-meta array, not global
  theme settings. Saves require a profile-specific nonce and `edit_user`.
- Computed: published-post total, distinct review-post count, first surviving
  published story/date, years and category coverage. Review aliases are `review`
  and `reviews`. No private/draft/future posts, pages or other authors are counted.
- “First archived story” is not an inferred employment date. Personal favourites
  and selected work are explicit editorial choices, not inferred from frequency.
- Empty optional fields omit their sections. No avatar falls back to initials
  when WordPress's avatar API returns no image. Existing avatar plugins continue
  to own the actual portrait source.

## Templates and query behavior

`templates/author.html` retains the native inherited Query Loop, archive query and
pagination. Topic/year are native GET controls (`tz_topic`, `tz_year`) that keep
the author scope, reset the page on submit and work without new JavaScript.
Direct category membership is used, not parent/child rollups. Sidebar topic links
filter this author's archive, not the site's full category archive.

Selected work is one bounded query (maximum three) and appears only on the first
unfiltered page. Ownership and published status are rechecked at render time.
Those posts remain in the complete chronological archive intentionally. No
automated “best work” selection or exclusion changes the archive's completeness.

The coverage sidebar excludes generic labels such as News, Reviews, How To and
India from its top five. `techzei_tt5_author_topic_exclusions` can customize that
list. Favourites are independent of these exclusions.

Statistics use two prepared aggregate queries on a cold cache: up to 200 year
groups with an indexed first-story lookup, then up to 100 category groups.
Only data is cached in transients for 12 hours plus a request-local memo; no
user-specific rendered HTML is cached. `techzei_tt5_author_stats_ttl` permits a
bounded TTL override. Cache keys include author ID and the existing editorial
namespace. Existing post/taxonomy/settings invalidation is reused; status
transitions, direct category relationship removal and permanent post deletion
are also covered. Author reassignment invalidates both authors via that namespace.
Profile edits are not cached by this module; host/page caches still need purging.

The measured two/zero figures are aggregate query counts, not whole-request SQL
totals: native archive pagination, optional selected work, term/avatar APIs and
WordPress bootstrap have their own costs. An empty author needs one cold query.

Site Editor parts `author-header` and `author-discovery` remain editable. Saved
Author templates and more-specific author-slug/author-ID templates take normal
WordPress precedence. The theme never resets them. The secondary Topics strip is
omitted from this template to keep the author's work near the profile.

## Verification on 2026-10-15

- Real isolated WordPress 6.8.3, Twenty Twenty-Five, official SQLite Database
  Integration 3.1.0, PHP 8.5.10; 16 author integration checks passed.
- Cold statistics: exactly 2 aggregate queries; warm persisted transient after
  request memo reset and object-cache flush: 0 aggregate queries.
- In-app browser: 320, 375, 768, 1024 and 1280px author layout. No page overflow,
  one H1, aligned breadcrumbs, Reading Charcoal biography and no lazy/high image
  combinations. Screenshots inspected at 375 and 1280px.
- Topic=Apple/year=2026 showed 7 local fixture articles while lifetime totals
  stayed 259. Page two retained the author, with no Selected work section.
- Empty author displayed initials, no fabricated work statistics or empty rail.
- Logged-out mobile menu and search opened; Escape returned focus to their
  controls. Existing header interaction code was not changed.
- Homepage, category, search, 404 and single fixture smoke checks at 375/1280px showed
  one H1, no author stylesheet, no page overflow and no invalid image priorities.

Preview data is an isolated fixture dataset, including sample curated selections,
not an updated production author profile or a claim that editorial choices have
been made on the live site.

Limits: no production deployment, full PHPUnit suite, MySQL/MariaDB runtime,
PHP 7.4 runtime, WordPress 7.1 or exhaustive third-party-plugin compatibility run
is claimed. Source keeps PHP 7.4-compatible syntax; the existing CI matrix checks
7.4/8.3 after a future authorized push. `Tested up to: 6.8` is unchanged.
Test without JavaScript and with actual production avatar/SEO plugins on staging
before release. Re-run the optional real-site runner as documented in tests/README.
