# Techzei Magazine 3.2.0 editorial integration

The editorial layer remains server-rendered and WordPress-native. Existing
`techzei_tt5_*` functions and shortcode names are retained; no post content,
post metadata, taxonomy data, or database schema migration is required.

## Related reading

`[techzei_related_stories]` continues to render the existing related-story
module. Results are bounded to the configured 2–6 item count, never include the
current post, and are de-duplicated across stages. The resolver order is:

1. Optional editorial selections, only when `articles.related_mode` resolves to
   `editorial` or `editorial-first`, or when the
   `techzei_tt5_related_editorial_first` filter opts in.
2. Posts sharing the current post's tags.
3. Posts sharing the current post's most-specific categories, with child
   categories considered before their ancestors.

Each query is capped, uses `no_found_rows`, and is ordered by date descending
then post ID descending. Shared categories are queried with
`include_children => false`, so a broad parent category is not treated as a
specific match. Unrelated posts are not inserted simply to fill the count.

The optional editorial selection uses WordPress's native sticky-post IDs and
is filterable without storing new data:

```php
add_filter(
    'techzei_tt5_related_editorial_first',
    '__return_true'
);
```

To supply a different ordered selection, filter
`techzei_tt5_editorial_selection`. The callback receives the default sticky-post
IDs, current post ID, and requested limit. Final IDs are still bounded and
filtered for the current post and duplicates.

The new `Related Reading` pattern uses the preserved shortcode with
`heading="0"`, allowing the pattern's translated core heading to own the
section title. Existing uses without that attribute retain their original
heading and kicker.

## Native patterns

The theme auto-loads the PHP patterns in `patterns/` on WordPress 6.7+:

- **Review Verdict** — translated kicker, heading, summary prompt, and
  accessible score label; stable class `tz-review-verdict`.
- **Product Specifications** — translated core Table block with scoped column
  headers, a stable `tz-product-specifications-scroll` wrapper, inline native
  horizontal overflow, and screen-reader guidance for narrow screens.
- **Related Reading** — translated core heading and the bounded related-story
  shortcode; stable class `tz-related-reading`.

Site Editor users can insert and edit these patterns without changing existing
posts. The stable classes and filters are intended for template/style or
plugin integration; this work does not edit templates, styles, or the settings
schema.

## Integration requirements

- The theme must be loaded in WordPress 6.7+ with Twenty Twenty-Five installed.
- The existing bootstrap must continue loading `inc/editorial.php`.
- The scoped `articles.related_mode` resolver uses `automatic` by default and
  `editorial-first` to opt into sticky-post
  editorial picks. No settings UI is required for the fallback behavior.
- Integrators should place the Related Reading pattern where they want the
  module to appear; the existing related template part remains compatible.
- If a project uses a custom table style, retain the
  `tz-product-specifications-scroll` wrapper and preserve horizontal keyboard
  scrolling and the table header cells.
