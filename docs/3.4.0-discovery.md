# Techzei Magazine Theme 3.4.0 article discovery

This release adds discovery components to the existing block-theme article
chrome. It does not register classic widget areas, edit posts, or create a
newsletter integration.

## Settings additions

The existing versioned `techzei_tt5_settings` option gains the following
resolved values:

```php
'articles' => array(
    'breadcrumbs'       => true,
    'toc'               => true,
    'mobile_share_dock' => true,
),
'sidebar' => array(
    'more_in_topic'    => true,
    'more_topic_count' => 4, // 2–6
    'newsletter_slot'  => false,
    'review_max_age'   => 5, // 1–10 years
    'follow_techzei'   => true,
),
```

They use the same Settings API sanitization, `edit_theme_options` capability,
and scoped reset as prior settings. A reset deletes only
`techzei_tt5_settings`; it never changes posts, templates, template parts,
menus, media, Global Styles, Yoast, or plugins.

## Template parts and precedence

`article-sidebar` is a template part, not a widget area. Its default order is:

1. More in this topic
2. Latest stories
3. Newsletter CTA slot
4. Latest reviews
5. Follow Techzei

An empty or disabled module is removed without a spacer. If an editor removes
one of these template parts from a saved Site Editor template, the theme does
not recreate it. A post’s explicit **Article with sidebar** or **Article
without sidebar** template selection continues to override the site default.

The newsletter CTA part is empty and disabled by default. After selecting a
provider, enable the setting and add that provider’s native block in the Site
Editor. The theme does not ship a signup SDK, endpoint, tracking tag, or form
processor.

## Breadcrumbs, TOC, and sharing

When Yoast SEO is active, the Breadcrumbs part renders Yoast’s own breadcrumb
output. Configure breadcrumb display and schema in Yoast; the theme does not
emit a duplicate `BreadcrumbList`. Without Yoast, the theme renders a visible,
plain-HTML `Home → Category → Title` trail (archives use `Home → Archive`) and
intentionally adds no breadcrumb schema.

The TOC is enabled only for posts assigned to a How To or Explainer category
(including an ancestor term) with at least three H2/H3 headings. It is native
HTML with `<details>` and heading anchors, so it remains usable without a
frontend dependency. The content’s existing heading IDs are preserved.

The mobile share dock is rendered only on single posts, only while sharing is
enabled, and only when at least one destination is selected. WhatsApp is first
in its mobile order; the regular share row remains in the article flow.

## Related-story order

Automatic related stories remain bounded and exclude the current article.
They now prefer, in order: an eligible editorial selection (only in
`editorial-first` mode), posts sharing both a tag and category, posts sharing a
tag, and posts sharing the most-specific categories. Automatic queries use a
five-year freshness window by default. Integrations can adjust that policy with
the `techzei_tt5_related_freshness_date_query` filter; unrelated posts are
never inserted merely to reach the requested count.

## Manual checks

- Open a current How To with three or more H2/H3 headings: breadcrumb, TOC
  anchors, sidebar order, related stories, and WhatsApp-first mobile dock.
- Open an Explainer and a normal article: TOC should appear only where eligible.
- Open an archive: show `Home → Archive` once, with no duplicate Yoast trail.
- Turn each discovery setting off and confirm no empty wrapper remains.
- Check 375px and 900px: the sidebar stacks below the article; the dock does
  not cover article-end controls.
